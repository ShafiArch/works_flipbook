# Notes for Claude

Read `HANDOFF.md` first: it explains the book, the data model, the viewer, the page
order tool, the robot that prepares pages, and the cache rule (`?v=N` in both HTML
pages whenever a .js or .css file changes). `GUIDE.md` is the owner's manual; keep it
in step with any change.

Writing rule for everything in this repository (code comments, docs, JSON, site text):
no em dashes or en dashes. Use commas, semicolons, parentheses or periods.
