# works_flipbook

Shafiul Islam's architecture portfolio as a page-turning book:
https://shafiarch.github.io/works_flipbook/

- `pages/` holds the page images at full size; the viewer uses the smaller copies in
  `pages/web/` and `pages/thumb/`, which the Book upkeep workflow makes.
- `content/book.json` is the order; change it with the page order tool at
  https://shafiarch.github.io/works_flipbook/manage.html
- `GUIDE.md` explains everything else.
